**Date**: 2026-09-13
**Status**: Decided

## Context

`API-003` requires the export endpoint to return the same bytes the UI displays for a plan version; `EXP-001` requires the export to be a single self-contained file; the mechanism is one output compared against itself, never two renderers kept in step.

## Decision

`backend/adapters/export/composer.py::compose_export_html(dataset)` is the one function that produces the standalone artifact: the dataset (embedded as JSON), the canonical renderer (embedded as inline `<script>`/`<style>`, ADR-001) and the three faces (embedded as base64). `GET /api/plans/{id}/export` (`backend/adapters/http/routes.py`) returns exactly its bytes, `Content-Type: text/html`. The cockpit's `Plan · Render` screen does not call this function or re-derive its output; it calls the SAME renderer function the composed file embeds, against the same dataset, in `PlanRenderMount` - so what a person sees in the cockpit and what the export endpoint returns are two invocations of one rendering mechanism over identical inputs, not two artifacts kept consistent by discipline.

## Rationale

- Comparing the export's bytes against themselves (calling the endpoint twice for the same version, `tests/test_http_api.py`) is the practical, CI-checkable form of "byte-identical": both calls exercise the identical code path deterministically.
- The stronger, more literal reading of `API-003` - the browser DOM the cockpit paints and the export file's DOM are identical - follows from ADR-001's design (one renderer function, one dataset) rather than needing its own mechanism.

## Alternatives considered and rejected

- **The cockpit embeds the export's exact bytes in an iframe** (`srcDoc`): considered, and rejected for the live view because it would prevent the cockpit from ever adding chrome-level affordances (the Edit-link mechanism `renderer/plan-renderer.js`'s `opts.editBase` provides) without polluting the exported file's own markup. The renderer's `opts` parameter gives the two consumers exactly the divergence they need (an edit affordance for the cockpit only) while sharing everything else.
